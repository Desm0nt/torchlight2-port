# Установка Torchlight II Mobile — по шагам

English version: [INSTALL.md](INSTALL.md).

Torchlight II Mobile запускает на Android-телефоне **вашу собственную копию** Torchlight II для Nintendo Switch. В проекте
нет файлов игры, и он никогда не раздаёт ни игру, ни ключи консоли: вы снимаете их со своего Switch. Программа установки на
ПК превращает ваш дамп в папку игры (~2 ГБ), вы копируете её на телефон и ставите приложение.

Всё занимает около 15 минут, в основном копирование.

## Что понадобится

**С вашего Switch** (см. шаг 1):

| Что | Подробности |
|---|---|
| Базовая игра Torchlight II | title id `010090400D366000`, с картриджа или из eShop |
| Обновление Torchlight II **v327680** | title id `010090400D366800` (выпуск 5, последнее). Работает только это обновление (порт сделан под его код). Программы дампа обычно пишут его в имя файла, например `...[010090400D366800][v327680].nsp` |
| `prod.keys` | ключи **вашей** консоли |

Языковые пакеты не нужны: все языки игры (в том числе русский) уже есть в базовой игре. DLC с питомцем Yapper пока не
используется.

Игра и обновление могут быть в **NSP, NSZ, XCI или XCZ**, в любом сочетании. Подходят и разбитые дампы с карты FAT32
(папка с частями `00`, `01`, … или `name.xc0`, `name.xc1`, …). Имена файлов не важны: установка узнаёт их по содержимому.

**ПК** с Windows 10/11 (64-бит), Linux или macOS:

- около **4 ГБ свободного места** на время подготовки (до ~6 ГБ с NSZ / XCZ);
- интернет при первом запуске: установка скачивает несколько вспомогательных программ (пакеты Python ~40 МБ, Microsoft
  .NET ~300 МБ и, на Windows без Python, сам Python ~15 МБ). Перед каждой загрузкой она спрашивает и кладёт всё только в
  свою папку. Следующие запуски работают без интернета.

**Телефон:**

- Android 12 или новее, 64-бит (Android 10 и 11 — отдельный APK `-android10`, шаг 6);
- **рекомендуется Snapdragon с GPU Adreno** (проверено на Snapdragon 8 Gen 3; телефоны с Mali / PowerVR / Xclipse работают
  на своём драйвере с обходами в движке и не проверялись);
- 8 ГБ ОЗУ или больше;
- около **3 ГБ свободно** во внутренней памяти;
- USB-кабель (или другой способ скопировать папку на телефон).

## Шаг 1. Снимите файлы игры и ключи со своего Switch

**Самостоятельный дамп.** Нужен Switch, на котором запускается homebrew (как этого добиться, здесь не описано).
1. Установите на Switch игру и последнее обновление (v327680).
2. Снимите их через [nxdumptool](https://github.com/DarkMatterCore/nxdumptool): установленная или eShop-копия → *NSP*;
   картридж → *XCI* (установленное обновление снимается отдельно как NSP). Для NSP включите
   **«remove console specific data»** — иначе обновление не прочитается на ПК.
3. Снимите ключи консоли через [Lockpick_RCM](https://github.com/shchmue/Lockpick_RCM). На SD-карте в `switch/` появится
   `prod.keys`.
4. Скопируйте файлы на ПК.

Не скачивайте файлы игры и ключи из интернета и не раздавайте свои.

## Шаг 2. Скачайте установку Torchlight II Mobile

Скачайте этот репозиторий архивом (зелёная кнопка **Code** → **Download ZIP**) или клонируйте и распакуйте на диск, где
хватает места, в короткий путь вроде `D:\TL2-setup`. Внутри будут `setup.bat`, `setup.sh` и папка `put-game-files-here`.

## Шаг 3. Положите файлы в `put-game-files-here`

```
<папка установки>/
├── setup.bat
├── setup.sh
└── put-game-files-here/
    ├── Torchlight II ... [010090400D366000] ... .nsp              (или .nsz / .xci / .xcz — базовая игра)
    ├── Torchlight II ... [010090400D366800][v327680] ... .nsp     (обновление)
    └── prod.keys
```

Можно положить туда и папку из программы дампа целиком (установка смотрит на две папки вглубь).

## Шаг 4. Запустите установку

### Windows

1. **Дважды щёлкните `setup.bat`.** Если Windows предупреждает о файле из интернета, выберите **Выполнить** (или
   **Подробнее → Выполнить в любом случае**).
2. Отвечайте **Y** и Enter (просто Enter — тоже «да»): *Скачать отдельный Python?* (только если на ПК нет Python 3.10+),
   *Установить пакеты Python?*, *Скачать и установить .NET 10 SDK?* Всё ставится в `tools\.runtime` внутри папки
   установки. В систему ничего не ставится, права администратора не нужны.
3. **Ждите.** Установка показывает семь пронумерованных этапов с прогрессом:

   | Этап | Обычно занимает |
   |---|---|
   | 1. Поиск и проверка файлов игры | секунды |
   | 2. Проверка программ и свободного места | секунды (в первый раз — загрузка .NET) |
   | 3. Извлечение программы игры | секунды |
   | 4. Патч программы под Android | меньше минуты |
   | 5. Проверка патча | 1–5 мин |
   | 6. Извлечение данных игры (~1,9 ГБ) | 1–5 мин |
   | 7. Перевод шейдеров | 1–3 мин |

   Свободное место проверяется до начала, при ошибке установка сразу останавливается с понятным сообщением. Если окно
   закрылось или ПК выключился — просто запустите установку снова: готовые этапы пропускаются.
4. В конце она показывает, где готовая папка, команды adb для копирования и что делать дальше.

Вместо `put-game-files-here` можно перетащить файлы прямо на `setup.bat`.

### Linux / macOS

1. Нужен Python 3.10 или новее с модулем `venv` (Debian / Ubuntu: `sudo apt install python3 python3-venv python3-pip`;
   Fedora: `sudo dnf install python3 python3-pip`; Arch: `sudo pacman -S python python-pip`; macOS: `brew install python@3.12`).
2. Откройте терминал в папке установки и выполните `bash setup.sh`. Отвечайте **Y** и ждите (этапы те же, что на Windows).
   Пакеты Python ставятся в `tools/.runtime/venv`, .NET — в `tools/.runtime/dotnet`.

Файлы можно передать и напрямую, в любом порядке: `bash setup.sh ~/dumps/tl2-base.nsp ~/dumps/tl2-update.nsp ~/prod.keys`.

### Не понятно, чего не хватает?

Запустите `setup.bat check` (Windows, в терминале в папке установки) или `bash setup.sh check`. Он покажет программы,
найденные файлы игры, что уже подготовлено и следующий шаг — ничего не меняя.

## Шаг 5. Скопируйте папку игры на телефон

Готовая папка — **`work/Torchlight2Mobile`** внутри папки установки.

- **Передача файлов по USB:** подключите телефон, выберите **Передача файлов**, откройте **внутреннюю память** телефона →
  **Download** и скопируйте туда всю папку **`Torchlight2Mobile`**. Должно получиться ровно так:

  ```
  Внутренняя память/Download/Torchlight2Mobile/romfs/...
  Внутренняя память/Download/Torchlight2Mobile/dm/out/...
  Внутренняя память/Download/Torchlight2Mobile/dm/shaders/...
  Внутренняя память/Download/Torchlight2Mobile/mods/          (сюда кладутся моды с PC, см. ниже)
  ```

- **adb (отладка по USB):** `setup.bat push` / `bash setup.sh push` копирует только недостающее и продолжает после обрыва;
  установка печатает и обычные команды `adb push`.

## Шаг 6. Установите приложение

Установите APK из [последнего релиза](https://github.com/Desm0nt/torchlight2-port/releases/latest) или соберите сами
(`build.bat`, см. *Building* в [README](../README.md)). В первый раз Android попросит разрешить установку приложений из
браузера или файлового менеджера.

- Android 12 или новее: `Torchlight2-Mobile-v<версия>-arm64.apk` (`TL2-port-debug.apk`, если собираете сами).
- Android 10 или 11: `Torchlight2-Mobile-v<версия>-arm64-android10.apk` (та же игра для старого Android; просит
  разрешение на хранилище вместо «Доступа ко всем файлам»; на настоящем Android 10 ещё не проверялся).

## Шаг 7. Первый запуск

1. Запустите **Torchlight II Mobile**.
2. Он попросит **Доступ ко всем файлам** (нужен, чтобы читать `Download/Torchlight2Mobile`). Включите и вернитесь.
3. Первый запуск и первые загрузки дольше последующих. Кнопка-шестерёнка открывает меню паузы и настройки порта
   (язык, форма картинки / широкий экран, док / портативный режим, лимит кадров, драйвер, управление, моды).

**Сенсорное управление:** стик хода появляется под левым большим пальцем в любом месте слева внизу; навыки — в веере
справа (II переключает второй набор навыков); тонкий ползунок у правого края — зум камеры; тап по мини-карте — большая
карта. Меню работают прямым тапом по пунктам; списки и длинные тексты прокручиваются свайпом. *Настройки игры… →
Редактировать раскладку…* позволяет двигать, менять размер и скрывать любые элементы; боковая раскладка выносит каждую
кнопку в отдельную ячейку по краям экрана.

Сохранения и настройки хранятся в памяти приложения. Установка новой версии APK поверх старой их сохраняет; меню паузы
умеет экспортировать и импортировать сохранения.

## Моды с PC (по желанию)

1. Скопируйте моды Torchlight II для PC (файлы `.MOD`, сделанные в GUTS) в `Download/Torchlight2Mobile/mods/` на телефоне.
2. В игре: шестерёнка → *Настройки игры…* → **Моды (вкл.: N)…**, отметьте нужные и расставьте порядок стрелками (мод ниже
   в списке побеждает, если два меняют один файл), затем *Сохранить*.
3. Закройте игру и запустите снова. Приложение один раз сконвертирует отмеченные моды (для больших модов показывается
   окно прогресса). Пока включён хоть один мод, игра пользуется отдельной папкой сохранений (копия ваших сохранений,
   сделанная в первый раз); обычные сохранения не меняются — снимите все галочки, чтобы вернуться к ним.

Используются данные, модели, текстуры и звуки модов. Изменения интерфейса PC-версии — нет (у версии для Switch свой
консольный интерфейс), поэтому моды, которым нужны новые экраны интерфейса или DLL-плагины, полностью работать не будут.

## Проблемы / FAQ

**«your Torchlight II update is v… ; only v327680 is supported»** — снимите обновление v327680 (выпуск 5).

**«the Torchlight II base game / the update … is not among the files»** — установка перечисляет все найденные файлы с
title id и версией; проверьте, что в `put-game-files-here` лежат нужные файлы.

**«prod.keys not found» / «your prod.keys has no …» / «does not decrypt with this prod.keys»** — нужны ключи той консоли,
с которой снят дамп, снятые свежим Lockpick_RCM. `title.keys` — другой файл.

**«personalized ticket» / «no ticket for rights id»** — снимите NSP заново с включённым в nxdumptool *remove console
specific data* (и с тикетом).

**«not enough free space»** — освободите место или вынесите рабочую папку на другой диск: `setup.bat --work D:\tl2-work`
(Windows) или `bash setup.sh --work /mnt/big/tl2-work`.

**Где выбрать язык?** — шестерёнка → *Настройки игры…* → *Язык игры*, затем перезапустите игру. Все языки встроены.

**Не играет вступительный ролик** — в этой версии видео пропускаются, игра просто идёт дальше.

**Мод ничего не меняет / с модом что-то не так** — снимите с него галочку в *Модах* и перезапустите. Моды, заменяющие
интерфейс PC-версии или добавляющие классы без консольных ресурсов, не поддерживаются. В `boot.log` строки `[tl2 mods]`
показывают, что было сконвертировано.

**Чёрный экран или приложение закрывается** — откройте шестерёнку → *Драйвер Vulkan* → попробуйте *Системный*,
перезапустите. Затем откройте issue в этом репозитории: модель телефона, версия Android, что произошло, и приложите всю
папку `Download/Torchlight2Mobile/logs/`: после падения следующий запуск пишет туда `crash.txt` (с логом упавшего запуска)
и сообщает об этом на экране; `boot.log` и `logcat.txt` текущего запуска и `boot.prev.log` / `logcat.prev.txt`
предыдущего пишутся построчно во время игры (поэтому остаются, даже если Android убил игру). Каждый запуск установки
пишется в `work/setup.log`: прикладывайте его при проблемах с установкой.

Технические подробности подготовки (что делает каждый шаг, ручной запуск): [tl2/GAME_FILES.md](tl2/GAME_FILES.md) (англ.).
