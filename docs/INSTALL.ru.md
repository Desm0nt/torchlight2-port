# Установка Diablo III Mobile — по шагам

English version: [INSTALL.md](INSTALL.md).

Diablo III Mobile запускает на Android-телефоне **вашу собственную копию** Diablo III: Eternal Collection для Nintendo
Switch. В проекте нет файлов игры, и он никогда не распространяет файлы игры или ключи консоли: вы снимаете их со своей
Switch. Программа установки на ПК превращает ваш дамп в папку игры (~16 ГБ, +5–6 ГБ на каждый языковой пакет), вы
копируете её на телефон и ставите приложение.

Всё вместе занимает около часа, в основном ожидание.

## Что нужно

**С вашей Switch** (см. шаг 1):

| Что | Подробности |
|---|---|
| Базовая игра Diablo III | title id `01001B300B9BE000`, с вашего картриджа или из eShop |
| Обновление **v1441792** | title id `01001B300B9BE800` (патч игры 2.7.7). Подходит только это обновление (порт сделан под его код). Программы дампа обычно пишут версию в имя файла: `...[01001B300B9BE800][v1441792].nsp` |
| `prod.keys` | ключи **вашей** консоли |
| *по желанию:* языковой пакет | только для языка кроме английского: например, Russian Language Pack `01001B300B9BF00A` |

Игра и обновление могут быть **NSP, NSZ, XCI или XCZ**, в любом сочетании. Подходят и разбитые дампы с карты FAT32
(папка с частями `00`, `01`, … или `name.xc0`, `name.xc1`, …). Имена файлов не важны: установка узнаёт файлы по содержимому.

**ПК** с Windows 10/11 (64 бит), Linux или macOS:

- около **20 ГБ свободного места** на время подготовки (+5–6 ГБ на языковой пакет; до ~35 ГБ с NSZ / XCZ);
- интернет при первом запуске: установка скачивает вспомогательные программы (пакеты Python ~40 МБ, Microsoft .NET
  ~300 МБ и, на Windows без Python, сам Python ~15 МБ). Перед каждой загрузкой она спрашивает и кладёт всё только в свою
  папку. Следующие запуски работают без интернета.

**Телефон:**

- Android 12 или новее, 64 бит (Android 10 и 11 — отдельный APK `-android10`, шаг 6);
- **рекомендуется Snapdragon с GPU Adreno** (проверено на Snapdragon 8 Gen 3; телефоны с Mali / PowerVR / Xclipse работают
  на своём драйвере с фолбэками движка и не проверялись);
- 8 ГБ ОЗУ или больше;
- около **17 ГБ свободного места** во внутренней памяти (+5–6 ГБ на языковой пакет);
- USB-кабель (или другой способ скопировать папку на телефон).

## Шаг 1. Снимите файлы игры и ключи со своей Switch

Нужна Switch, на которой запускается homebrew (как этого добиться, здесь не описано).
1. Установите на Switch игру, последнее обновление (v1441792) и, если нужно, языковой пакет.
2. Снимите их через [nxdumptool](https://github.com/DarkMatterCore/nxdumptool): установленная копия или eShop → *NSP*;
   картридж → *XCI* (установленные обновление и DLC снимаются отдельно как NSP). Для NSP включите
   **«remove console specific data»** — иначе обновление не прочитать на ПК.
3. Снимите ключи консоли через [Lockpick_RCM](https://github.com/shchmue/Lockpick_RCM): `prod.keys` появится на SD-карте в `switch/`.
4. Скопируйте файлы на ПК.

Не скачивайте файлы игры и ключи из интернета и не раздавайте свои.

## Шаг 2. Скачайте установку Diablo III Mobile

Скачайте этот репозиторий ZIP-архивом (зелёная кнопка **Code** → **Download ZIP**) или клонируйте его и распакуйте на
диск с достаточным местом, в короткий путь вроде `D:\D3-setup`. Внутри будут `setup.bat`, `setup.sh` и папка
`put-game-files-here`.

## Шаг 3. Положите файлы в `put-game-files-here`

```
<папка установки>/
├── setup.bat
├── setup.sh
└── put-game-files-here/
    ├── Diablo III ... [01001B300B9BE000] ... .nsp              (или .nsz / .xci / .xcz — базовая игра)
    ├── Diablo III ... [01001B300B9BE800][v1441792] ... .nsp    (обновление)
    ├── Diablo III ... [DLC Russian Language Pack] [01001B300B9BF00A] ... .nsp   (по желанию)
    └── prod.keys
```

Можно положить и папку из программы дампа как есть (установка смотрит на две папки вглубь).

## Шаг 4. Запустите установку

### Windows

1. **Дважды щёлкните `setup.bat`.** Если Windows предупреждает о файле из интернета, выберите **Выполнить**
   (или **Подробнее → Выполнить в любом случае**).
2. Отвечайте **Y** и Enter (просто Enter — тоже «да»): *скачать свой Python?* (только если на ПК нет Python 3.10+),
   *установить пакеты Python?*, *скачать и установить .NET 10 SDK?* Всё ставится в `tools\.runtime` внутри папки
   установки, ничего не ставится в систему, права администратора не нужны.
3. **Ждите.** Установка показывает восемь пронумерованных этапов с прогрессом:

   | Этап | Обычно |
   |---|---|
   | 1. Поиск и проверка файлов игры | секунды |
   | 2. Проверка инструментов и места | секунды (в первый раз — загрузка .NET) |
   | 3. Извлечение программы игры | меньше минуты |
   | 4. Патч программы под Android | меньше минуты |
   | 5. Проверка патча | 1–5 мин |
   | 6. Извлечение данных игры (~16 ГБ) | 15–45 мин |
   | 7. Перевод шейдеров | 2–10 мин |
   | 8. Языковые пакеты (по желанию) | по несколько минут |

   Перед началом она проверяет свободное место и при проблеме сразу останавливается с понятным сообщением. Если окно
   закрылось или ПК выключился — просто запустите установку снова: готовые этапы пропускаются.
4. В конце она показывает, где лежит готовая папка, команды adb для копирования и что делать дальше.

Вместо `put-game-files-here` можно просто перетащить файлы на `setup.bat`.

### Linux / macOS

1. Нужен Python 3.10 или новее с модулем `venv` (Debian / Ubuntu: `sudo apt install python3 python3-venv python3-pip`;
   Fedora: `sudo dnf install python3 python3-pip`; Arch: `sudo pacman -S python python-pip`; macOS: `brew install python@3.12`).
2. Откройте терминал в папке установки и выполните `bash setup.sh`. Отвечайте **Y** и ждите (этапы те же, что на Windows).
   Пакеты Python ставятся в `tools/.runtime/venv`, .NET — в `tools/.runtime/dotnet`.

Файлы можно передать и напрямую, в любом порядке: `bash setup.sh ~/dumps/d3-base.nsp ~/dumps/d3-update.nsp ~/prod.keys`.

### Не понятно, чего не хватает?

`setup.bat check` (Windows, в терминале в папке установки) или `bash setup.sh check` перечислит инструменты, найденные
файлы игры, что уже готово и следующий шаг — и ничего не изменит.

## Шаг 5. Скопируйте папку игры на телефон

Готовая папка — **`work/Diablo3Mobile`** внутри папки установки.

- **По USB (передача файлов):** подключите телефон, выберите **Передача файлов**, откройте **внутреннюю память** →
  **Download** и скопируйте туда всю папку **`Diablo3Mobile`**. Должно получиться ровно так:

  ```
  Внутренняя память/Download/Diablo3Mobile/romfs/...
  Внутренняя память/Download/Diablo3Mobile/dm/out/...
  Внутренняя память/Download/Diablo3Mobile/dm/shaders/...
  Внутренняя память/Download/Diablo3Mobile/aoc/10/...      (только с языковым пакетом)
  ```

- **Через adb (отладка по USB):** `setup.bat push` / `bash setup.sh push` копирует только недостающее и продолжает после
  обрыва; установка также печатает обычные команды `adb push`.

## Шаг 6. Установите приложение

Установите APK со страницы Releases этого репозитория или соберите сами (`build.bat`, см. «Building» в
[README](../README.md)). При первой установке Android попросит разрешить установку приложений из браузера или файлового менеджера.

- Android 12 и новее: `Diablo3-Mobile-v<версия>-arm64.apk` из [последнего релиза](https://github.com/Desm0nt/diablo3-port/releases/latest) (`D3-port-debug.apk`, если собираете сами).
- Android 10 или 11: `Diablo3-Mobile-v<версия>-arm64-android10.apk` (та же игра, собранная для старого Android; вместо «Доступа ко всем
  файлам» просит разрешение на хранилище; на настоящем Android 10 ещё не проверялась).

## Шаг 7. Первый запуск

1. Запустите **Diablo III Mobile**.
2. Приложение попросит **доступ ко всем файлам** (чтобы читать `Download/Diablo3Mobile`). Включите и вернитесь.
3. Первый запуск и первые загрузки дольше последующих. Шестерёнка открывает настройки порта (язык, форма картинки /
   широкий экран, лимит кадров, драйвер, управление). Для русского языка выберите его в «Язык игры» (пакет должен лежать
   в `aoc/10`) и перезапустите игру.

Сохранения и настройки хранятся в памяти приложения; установка нового APK поверх старого их сохраняет, а меню паузы
умеет экспортировать и импортировать сохранения.

## Проблемы / вопросы

**«your Diablo III update is v… ; only v1441792 is supported»** — снимите обновление v1441792 (патч 2.7.7).

**«the Diablo III base game / the update … is not among the files»** — установка перечисляет все найденные файлы с title id
и версией; проверьте, что в `put-game-files-here` лежат нужные файлы.

**«prod.keys not found» / «your prod.keys has no …» / «does not decrypt with this prod.keys»** — нужны ключи той консоли,
с которой сняты дампы, снятые свежим Lockpick_RCM. `title.keys` — другой файл.

**«personalized ticket» / «no ticket for rights id»** — снимите NSP заново с включённой опцией nxdumptool
*remove console specific data* (и с тикетом).

**Установка останавливается или пишет `!!` на этапе 8/8 (DLC)** — языковые и предметные паки необязательны: пак с ошибкой пропускается, папка игры всё равно собирается (игра тогда на английском). `setup.bat --no-dlc` / `bash setup.sh --no-dlc` пропускает все DLC. Каждый запуск пишется в `work/setup.log` — приложите его к issue.

**«not enough free space»** — освободите место или вынесите рабочую папку на другой диск: `setup.bat --work D:\d3-work`
(Windows) или `bash setup.sh --work /mnt/big/d3-work`.

**Игра остаётся на английском** — пакет нужного языка должен лежать в `Download/Diablo3Mobile/aoc/<индекс>` и быть
выбран в «Язык игры» в настройках; после этого перезапустите игру.

**Чёрный экран или приложение закрывается** — в настройках → «Драйвер Vulkan» попробуйте «Системный» и перезапустите.
Затем откройте issue в этом репозитории: модель телефона, версия Android и что произошло, и приложите
`Download/Diablo3Mobile/logs/crash.txt`: после падения следующий запуск пишет его туда (вместе с логом упавшего запуска) и
сообщает об этом на экране. В той же папке лежат `boot.log` и `logcat.txt` текущего запуска и `boot.prev.log` /
`logcat.prev.txt` предыдущего: они пишутся построчно прямо во время игры (поэтому остаются, даже если Android убил игру) —
приложите всю папку `logs`.

Технические подробности подготовки (что делает каждый шаг, как запускать инструменты вручную):
[d3/GAME_FILES.md](d3/GAME_FILES.md) (англ.).
